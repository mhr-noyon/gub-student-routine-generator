# 🎓 GUB Student Routine Generator

Welcome to the **Customized Routine Generator** project designed specifically for the students of **Green University of Bangladesh**. This tool aims to simplify the often frustrating task of creating a class routine that aligns with both student preferences and course teacher availability.

---

## 📌 Project Overview

Students often face difficulty in preparing an ideal routine that:

- Fits their preferred class days.
- Avoids conflicts in course schedules.
- Respects the availability of course teachers.

This project addresses those issues by **automatically generating all valid routine combinations** based on user-defined inputs.

---

## ⚙️ How It Works

1. You provide the **input manually** in the specified files.
2. The structure of the input files must be maintained strictly.
3. Once the input is ready, run the following file:

```bash
routine_draft.cpp
```
